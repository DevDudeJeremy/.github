# DevDudeJeremy on GitHub

This special `.github` repository powers the public [DevDudeJeremy organization profile](https://github.com/DevDudeJeremy) and supplies default community-health files for repositories across the organization.

## What lives here

- [`profile/README.md`](profile/README.md) — the organization landing page.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — organization-wide contribution guidance.
- [`SECURITY.md`](SECURITY.md) — the private vulnerability-reporting path.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — community participation standards.
- [`SUPPORT.md`](SUPPORT.md) — project support and consulting routes.
- [`.github/`](.github) — default issue forms, pull-request guidance, and ownership rules.

Repository-specific guidance takes precedence whenever an individual project provides its own version of one of these files.

## Explore the work

Visit [devdudejeremy.com](https://devdudejeremy.com) for project context, or browse the [public repositories](https://github.com/orgs/DevDudeJeremy/repositories) directly.
